# Solo Ski

Solo Ski is a lightweight trip finder for solo, car-free ski travel in the United States. It pairs selected Epic and Ikon resorts with public-transit routes and hostel candidates targeting $60 per night or less.

## Features

- Search by U.S. state or ski resort
- Filter by Epic Pass, Ikon Pass, and state
- Compare hostel listings on Booking and Expedia
- View typical shuttle and public-transit travel times
- Switch between eligible hostels when a resort has multiple options

## Run locally

This is a static website. Open `index.html` directly, or serve the directory with any static web server.

## Important

Accommodation prices, schedules, fares, and travel times are not live inventory. Always confirm dates, totals, operating days, and the final return trip with the linked provider.
